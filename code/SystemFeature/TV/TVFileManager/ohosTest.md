# 文件管理器 测试用例归档

## 用例表

|测试功能|预置条件|输入|预期输出|测试结果|
|--------------------------------|--------------------------------|--------------------------------|--------------------------------|--------------------------------|
|首页媒体分类入口展示|应用正常运行|进入首页|显示视频、图片、文档、音频、设备五个分类入口|Pass|
|本机存储Tab切换|应用正常运行|点击"本机"Tab|显示本机存储文件列表|Pass|
|外部存储Tab切换|应用正常运行且外部存储已挂载|点击"外部储存"Tab|显示外部存储文件列表|Pass|
|外部存储未挂载时切换Tab|应用正常运行且无外部存储|点击"外部储存"Tab|提示无外部存储设备或列表为空|Pass|
|视频分类浏览|应用正常运行且本机存在视频文件|点击视频分类入口|展示本机所有视频文件|Pass|
|图片分类浏览|应用正常运行且本机存在图片文件|点击图片分类入口|展示本机所有图片文件|Pass|
|文档分类浏览|应用正常运行且本机存在文档文件|点击文档分类入口|展示本机所有文档文件|Pass|
|音频分类浏览|应用正常运行且本机存在音频文件|点击音频分类入口|展示本机所有音频文件|Pass|
|文件列表进入子目录|应用正常运行|点击文件列表中的文件夹|进入该文件夹，展示子目录内容|Pass|
|文件列表返回上级目录|应用正常运行且已进入子目录|点击返回|返回上级目录，展示上级目录内容|Pass|
|创建文件夹|应用正常运行|点击新建文件夹，输入名称并确认|在当前目录下创建指定名称的文件夹|Pass|
|创建文件|应用正常运行|点击新建文件，输入名称并确认|在当前目录下创建指定名称的文件|Pass|
|重命名文件|应用正常运行|选中文件，点击重命名，输入新名称并确认|文件名称更新为新名称|Pass|
|重命名文件夹|应用正常运行|选中文件夹，点击重命名，输入新名称并确认|文件夹名称更新为新名称|Pass|
|删除文件|应用正常运行|选中文件，点击删除并确认|文件被移入回收站，列表中不再显示|Pass|
|删除文件夹|应用正常运行|选中文件夹，点击删除并确认|文件夹及其内容被移入回收站|Pass|
|复制文件|应用正常运行|选中文件，点击复制，选择目标目录并确认|文件被复制到目标目录|Pass|
|移动文件|应用正常运行|选中文件，点击移动，选择目标目录并确认|文件被移动到目标目录，原目录不再显示|Pass|
|复制文件覆盖确认|目标目录已存在同名文件|复制文件到目标目录|弹出覆盖确认对话框|Pass|
|移动文件覆盖确认|目标目录已存在同名文件|移动文件到目标目录|弹出覆盖确认对话框|Pass|
|文件操作进度展示|执行大文件复制或移动|点击复制/移动|弹出进度对话框，展示操作进度|Pass|
|搜索文件|应用正常运行|在SearchBar输入关键词|展示匹配的文件列表|Pass|
|搜索无结果|应用正常运行|输入不存在的文件名|显示无搜索结果提示|Pass|
|存储空间展示|应用正常运行|查看StorageSpaceComponent|正确显示本机/外部存储的可用空间和总空间|Pass|
|文件分享|应用正常运行且已授权|选中文件，点击分享|文件分享功能正常执行|Pass|
|TV遥控器焦点切换|应用正常运行|使用遥控器方向键|焦点在组件间正确切换|Pass|
|文件访问权限未授予|应用首次启动且未授予权限|进入应用|弹出权限申请提示|Pass|
|文件访问权限被拒绝|用户拒绝文件读写权限|尝试浏览文件|提示权限不足，无法访问|Pass|
|外部存储设备突然移除|正在浏览外部存储文件|拔出外部存储设备|提示存储设备已移除，返回本机存储|Pass|
|空目录展示|进入无文件的目录|浏览空目录|显示空目录提示|Pass|
