## 简介
ApplicationManager是OpenHarmony中预置的系统应用，管理系统中已安装的应用，并提供启动应用的功能。

## TV特性
ApplicationManager作为OpenHarmony TV形态中独有的系统应用，从UX到功能都按照TV规范设计，符合TV形态的标准需求。
