# TVApplicationManager 测试用例归档

## 用例表

| 测试功能      | 预置条件                    | 输入             | 预期输出                                    | 是否自动 | 测试结果 |
|-----------|-------------------------|----------------|-----------------------------------------|------|---|
| 拉起应用      | 设备正常启动                  | 通过桌面图标启动       | 1、成功拉起应用并进入首页<br>2、显示设备安装应用             | 否    | Pass |
| 添加到桌面快捷方式 | 桌面不存在的应用图标              | 菜单键选择添加到桌面快捷方式 | 1、桌面显示对应应用图标<br>2、再次选择应用菜单键无添加到桌面快捷方式选项 | 否    | Pass |
| 卸载应用      | 1、选择可卸载应用<br>2、选择不可卸载应用 | 菜单键选择卸载选项      | 1、弹窗不可卸载<br>2、应用卸载成功,对应应用图标消失           | 否    | Pass |
| 移动应用      | 遥控或者键盘菜单键               | 菜单键选择移动选项      | 选中应用可移动自定义位置                            | 否    | Pass |
| 应用显示      | 设备未安装的应用                | 安装新应用          | 1、显示安装的应用图标<br>2、选中应用菜单键功能正常            | 否    | Pass |
