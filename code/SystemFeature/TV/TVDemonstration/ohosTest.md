# TVDemonstration 测试用例归档

## 用例表

| 测试功能 | 预置条件 | 输入 | 预期输出 | 是否自动 | 测试结果 |
|--------|--------|-----|--------|--------|--------|
| 产品规格页面展示 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap | 启动应用，进入"产品规格"标签页 | 正确显示屏幕尺寸、操作系统、处理器、接口配置等产品参数信息 | 否 | Pass |
| 功能特性页面展示 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap | 点击底部"功能特性"标签，查看功能列表 | 显示通用互联、投屏、智能AI、指向遥控、智慧屏保、语音交互、分布式等功能卡片 | 否 | Pass |
| 功能详情页跳转 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap | 在功能特性页点击任意功能卡片 | 跳转至对应功能详情页，显示功能图片和详细介绍文字，支持左右滑动切换功能 | 否 | Pass |
| 智慧生活页面展示 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap | 点击底部"智慧生活"标签 | 显示娱乐影音、儿童关怀、高效办公三个场景卡片 | 否 | Pass |
| 智慧生活详情页跳转 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap | 在智慧生活页点击任意场景卡片 | 跳转至对应场景详情页，自动播放场景视频，显示场景详细说明 | 否 | Pass |
| 服务支持页面展示 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap | 点击底部"服务支持"标签 | 显示服务支持轮播图，可通过左右箭头切换图片 | 否 | Pass |
| 底部导航Tab切换 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap | 依次点击底部"产品规格"、"功能特性"、"智慧生活"、"服务支持"Tab | 页面内容随Tab切换正确更新，当前选中Tab高亮显示 | 否 | Pass |
| 遥控器焦点导航 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap <br/> 3. 连接遥控器 | 使用遥控器方向键在各功能卡片、Tab之间移动焦点 | 焦点跟随方向键移动，聚焦元素显示高亮边框 | 否 | Pass |
| 屏保自动触发 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap <br/> 3. 屏保触发时长设置为5分钟 | 启动应用后保持静止5分钟不操作 | 自动跳转至屏保页面，轮播显示预设图片 | 否 | Pass |
| 屏保退出 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap <br/> 3. 屏保已激活 | 在屏保页面按任意遥控器按键或触碰屏幕 | 退出屏保，返回触发屏保前所在页面 | 否 | Pass |
| 应用前后台切换 | 1. 需在真机测试 <br/> 2. 构建并安装测试hap | 1. 打开应用 <br/> 2. 按Home键切至后台 <br/> 3. 重新打开应用 | 应用切至后台时停止屏保检测；重新切换到前台时恢复屏保检测，页面状态正常恢复 | 否 | Pass |
