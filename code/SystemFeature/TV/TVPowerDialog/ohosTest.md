# PowerDialog 测试用例归档

## 用例表

| 测试功能                | 预置条件                                                          | 输入                                  | 预期输出                                      | 是否自动 | 测试结果 |
|---------------------|---------------------------------------------------------------|-------------------------------------|-------------------------------------------|------|------|
| 电源对话框展示            | 1. 需在真机测试 <br/> 2. 构建并安装测试hap <br/> 3. 设备已正常启动              | 长按电源键或通过系统触发电源对话框                   | 弹出电源对话框，显示熄屏、关机、重启三个选项                    | 否    | Pass |
| 熄屏功能               | 1. 需在真机测试 <br/> 2. 构建并安装测试hap <br/> 3. 电源对话框已弹出              | 点击或遥控器选中"熄屏"按钮并确认                   | 屏幕熄灭，发送熄屏公共事件                             | 否    | Pass |
| 关机功能               | 1. 需在真机测试 <br/> 2. 构建并安装测试hap <br/> 3. 电源对话框已弹出              | 点击或遥控器选中"关机"按钮并确认                   | 设备正常关机                                    | 否    | Pass |
| 重启功能               | 1. 需在真机测试 <br/> 2. 构建并安装测试hap <br/> 3. 电源对话框已弹出              | 点击或遥控器选中"重启"按钮并确认                   | 设备正常重启                                    | 否    | Pass |
| 遥控器焦点导航            | 1. 需在真机测试 <br/> 2. 构建并安装测试hap <br/> 3. 电源对话框已弹出 <br/> 4. 使用遥控器 | 使用遥控器方向键在熄屏、关机、重启按钮间切换              | 焦点在各按钮间正常切换，选中项高亮显示                       | 否    | Pass |
| 鼠标悬停交互             | 1. 需在真机测试 <br/> 2. 构建并安装测试hap <br/> 3. 电源对话框已弹出 <br/> 4. 连接鼠标 | 鼠标移动至各按钮上                           | 按钮高亮，鼠标样式切换为点击样式                          | 否    | Pass |
| 返回键关闭对话框           | 1. 需在真机测试 <br/> 2. 构建并安装测试hap <br/> 3. 电源对话框已弹出              | 按遥控器返回键或系统返回手势                      | 电源对话框关闭，回到上层界面                            | 否    | Pass |
